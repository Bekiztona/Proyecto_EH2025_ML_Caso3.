# Guía breve para publicar en GitHub

1. Inicia sesión en GitHub.
2. Selecciona **New repository**.
3. Nombre: `Proyecto_EH2025_ML_Caso3`.
4. Visibilidad: **Public** (requisito de la tarea).
5. No inicialices con archivos si vas a subir esta carpeta completa.
6. Descomprime el ZIP y sube el contenido de la carpeta raíz del proyecto.
7. Verifica que GitHub muestre `README.md`, `notebooks/`, `src/`, `outputs/`, `docs/`, `requirements.txt` y `.gitignore`.
8. Comprueba que `data/raw/` no contenga microdatos antes de publicar.
9. Copia la URL pública del repositorio y pégala en Moodle.

## Opción desde la web
En el repositorio, usa **Add file → Upload files**, arrastra los archivos del proyecto (no la carpeta comprimida si el sitio no la acepta) y confirma el commit.

## Antes de hacer público
- Revisa el contenido de cada archivo.
- Confirma que no hay `.sav`, `.dta`, `.rar`, tokens, credenciales ni información personal.
- Sustituye la fecha de acceso provisional del README/PDF por la fecha real de descarga.
